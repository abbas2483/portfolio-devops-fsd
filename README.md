## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Project structure

Personal portfolio content is maintained centrally in `src/data/portfolio.ts`. Update that file when changing contact links, skills, or projects so the site remains consistent.
